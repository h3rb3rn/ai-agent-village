# P02.3 – Canonical authority entrypoint

The authority daemon now has a versioned executable entrypoint,
`scripts/authority-server.py`, which delegates to the tested `village.authority`
module. The bootstrap overlays it at the existing service path, preserving the
systemd contract while removing the historical embedded daemon from the fresh
install path.

Verification: shell syntax and the four canonical-source tests are
`LOCAL_VERIFIED`. The existing live-socket authority test was not used as an
acceptance test in this unprivileged workspace: it cannot bind its privileged
socket here (`PermissionError: Operation not permitted`). No authority socket,
groups, or running service were changed on the host in this package.
