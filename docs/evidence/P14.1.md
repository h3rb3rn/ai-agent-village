# P14.1 – Backward-compatible memory schema migration

Status: `LOCAL_VERIFIED`

The memory gateway now inspects the existing `memories` table before creating
indexes. Older databases are upgraded additively with `updated_at` and
`idempotency_key`; legacy rows retain their content and use `created_at` as the
initial update timestamp. The migration is idempotent and does not delete or
rewrite memory content.

Verification:

```text
python3 -m unittest tests.test_memory_gateway -v
... Ran 11 tests ... OK
```

The regression test creates the pre-migration schema, inserts a row, opens the
gateway, and verifies both new columns and the original row. Host deployment and
projection rebuild are tracked separately; no simulation restart is performed by
this package.
