# P23.1 – Read-only Neuinstallations-Vorprüfung

`scripts/preflight-install.py` prüft vor einem Bootstrap-Lauf das Release-Manifest,
Shell-Syntax, Python-Kompilierung und grundlegende Host-Kommandos. Das Werkzeug
ist read-only, startet keine Services, lädt keine Modelle und verändert keine
`.env`-Datei. Bei fehlenden Quellen bricht es fail-closed ab.

## Nachweis

- `python3 -m unittest tests.test_preflight_install -v` – LOCAL_VERIFIED
- Aktuelle Arbeitskopie besteht die Vorprüfung.
- Unvollständige temporäre Kopie wird abgewiesen.
- Kein Host-Rollout und kein Simulationsstart in diesem Paket.

## Offen

Ein echter Lauf auf einer frischen Debian-13-VM bleibt für P23.2 erforderlich.
