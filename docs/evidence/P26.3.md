# P26.3 – Mock-End-to-End-Canary

Das lokale Mock-Szenario validiert alle sieben Canary-Schritte und verlangt je
Schritt eine synthetische Evidenzreferenz. Es meldet explizit `execution: 0`;
damit kann ein Testlauf keine Agenten, Modelle, Container oder Netzwerke starten.

## Nachweis

- `python3 -m unittest tests.test_rollout_evidence tests.test_rollout_scenario -v` – LOCAL_VERIFIED
- Keine Host-Änderung und kein Simulationsstart in diesem Paket.

## Offen

Die gleichen Schritte müssen später in einer isolierten Canary-Umgebung mit
echten Request-, Task-, Artefakt- und Memory-Belegen wiederholt werden.
