# P22.4 – Responsive memory substrate dashboard

Date: 2026-09-26

## Scope

Make the dashboard's memory services and per-agent memory cards usable on narrow
desktop and mobile viewports without horizontal overflow.

## Implementation

- Replaced fixed three-column memory grids with `auto-fit/minmax` fluid cards.
- Added `min-width: 0`, overflow-safe URLs and text truncation.
- Memory service cards now use a consistent responsive card height.
- Agent memory cards use a two-row layout on wide screens and one column of
  cards below 560px.
- Existing themes and color modes remain inherited from the dashboard tokens.
