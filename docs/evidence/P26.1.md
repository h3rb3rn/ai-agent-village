# P26.1 – Gestufter Canary-Plan ohne Start

`village.rollout` validiert einen Canary-Plan mit einem Agenten, Release-Revision,
persistentem Pausezustand und expliziter Betreiberfreigabe. Das Ergebnis ist
ausschließlich `planned_only`; es gibt keinen Systemd-, Inferenz- oder Netzwerkaufruf.

## Nachweis

- `python3 -m unittest tests.test_rollout -v` – LOCAL_VERIFIED
- Fehlende Freigabe und aufgehobene Pause werden fail-closed abgewiesen.
- Keine Host-Änderung und kein Simulationsstart in diesem Paket.
