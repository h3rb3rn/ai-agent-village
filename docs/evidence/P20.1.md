# P20.1 – CSRF-geschützter Kontaktkanal

Der authentifizierte öffentliche Kontaktkanal erzeugt pro Session einen
zufälligen CSRF-Token. Das Frontend bezieht ihn über `/contact/status` und sendet
ihn als Formularfeld; POSTs ohne passenden Token werden mit HTTP 403 abgewiesen.
Legacy-Sessions ohne Token werden nicht stillschweigend akzeptiert.
