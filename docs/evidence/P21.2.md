# P21.2 – Shared event envelope for passive sources

Firewatch alerts and meeting-open events now use the same versioned envelope as
runtime events (`schema_version`, `event_id`, `run_id`, UTC timestamp, source and
kind). Existing payload fields remain available. This makes passive telemetry
and social interventions comparable without introducing a new event broker.
