# P115 – Prüfung: Antwort auf die Lektion des Tages als Nachweis

## Befund (HOST_VERIFIED, 2026-10-09, 22:44 UTC)

- Die Schule hat Lektionen (P113), aber keine Möglichkeit, dass ein Agent das Gelernte nachweist. Ohne Nachweis gibt es keine Prüfung.

## Änderung

- `village/school.py`: `record_answer()` speichert pro Agent und Tag eine Antwort auf die Lektion des Tages. Eine Antwort muss mindestens 40 Zeichen haben, und es muss eine Lektion für den Tag geben. Pro Agent und Tag gibt es genau eine gespeicherte Antwort. `answers_for()` liest die Antworten eines Tages.
- `village/actions.py`, `web/decision.py`, `web/runtime.py`: `school_operation` mit `operation=answer` und Feld `answer`. Jeder Agent darf antworten, nur der König plant weiter.

## Tests (LOCAL_VERIFIED)

- `tests/test_school.py`: `LessonAnswerTests` (einmalige Speicherung, zu kurze Antwort, keine Lektion).
- Gesamte Suite: 1197 Tests OK.

## Offen

- Die inhaltliche Bewertung der Antworten (richtig oder falsch) ist nicht gebaut. Gespeichert wird, dass ein Agent geantwortet hat, nicht, ob die Antwort stimmt. Das ist der nächste Schritt, danach kann der Auditor die Antworten prüfen.
