# P122 – Nur das eigene Porträt wird angezeigt

## Befund (HOST_VERIFIED, 2026-10-10)

- Im Observatory sahen alte, generierte Porträts aus dem Katalog (`village/assets/ascii_art/*.txt`, vom 2. Oktober). Die Ursache: `get_resident()` nahm bei einem Profil ohne eigenes Porträt die Datei als Fallback. Auch bei angelegten Profilen mit leerem Porträt wurde so das alte Bild gezeigt.

## Änderung

`village/residents.py`:
- Angelegtes Profil: Porträt ist das eigene (`ascii_art`) oder leer. Keine Dateien mehr als Fallback.
- Nicht angelegtes Profil: Porträt ist leer.

## Tests (LOCAL_VERIFIED)

- `tests/test_residents.py`: `OwnPortraitOnlyTests` (nicht angelegtes Profil zeigt kein generiertes Porträt).
- Gesamte Suite: 1213 Tests OK.

## Offen

- Die generierten Dateien liegen noch auf dem Host und werden nicht mehr verwendet. Löschen bleibt eine eigene Entscheidung.
