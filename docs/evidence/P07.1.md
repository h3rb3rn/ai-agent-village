# P07.1 – Resident runtime resilience

Unexpected local runtime exceptions are now recorded as `runtime_exception`
events with an increasing streak and bounded exponential backoff. The resident
process remains alive instead of relying on opaque systemd restart loops. Model
inference errors continue to use their existing lifecycle classification.

Verification: resilience/runtime tests are `LOCAL_VERIFIED`. The intervention
must be included in future restart-rate measurements.
