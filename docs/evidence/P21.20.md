## Umgesetzt
- Web-UI (G10/G11): `/activity` überlebt Events ohne `name`/`role` (auf dem Host bricht die Verbindung ab,
  HTTP 000), API-Routen ignorieren Query-Strings, Login-Drosselung (5 Fehlversuche/15 min je Adresse),
  `Secure`-Cookie hinter TLS-Proxy, robuste `Content-Length`-Prüfung, Session-Bereinigung.
  `tests/test_webui_hardening.py` (6 HTTP-Tests; gegen den alten Code schlagen alle 6 fehl).
- Ressourcenlimits (G12): `scripts/install-runtime.py` schreibt je Agent-Unit `40-resource-limits.conf`
  (MemoryHigh 1,5 G, MemoryMax 3 G, TasksMax 512, CPUQuota 150 %, LimitFSIZE 4 G) und den Slice
  `ai-village-agents.slice` (10 G, 300 %). `tests/test_resource_limits.py`.
- Firewatch (G13): `agent_wedged` (≥ 3 Exceptions in Folge) und `agent_stalled` (30 min ohne fertige
  Inferenz), nur lesend, im Pausenzustand still. Tests in `tests/test_firewatch.py`.
- Parser (G14): Angehängter Text nach einem vollständigen Aktionsobjekt wird toleriert, zwei Objekte oder
  abgeschnittenes JSON bleiben abgelehnt. Tests in `tests/test_reliability.py`.
- Dokumentation (G17): Statuskopf, README-Status, Runbook.
