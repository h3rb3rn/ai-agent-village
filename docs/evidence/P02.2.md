# P02.2 – Canonical helper overlay

The bootstrap now overlays the reviewed repository implementations of the
agent runner, pause-aware resume helper and update helper. This prevents fresh
installs from silently restoring the older embedded helper implementations.

Verification: `bash -n bootstrap-ai-village.sh` and the canonical helper static
test are `LOCAL_VERIFIED`. The embedded authority daemon remains a separate
follow-up because it has no one-to-one canonical executable yet.
