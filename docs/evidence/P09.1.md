# P09.1 – Authoritative message projection

SQLite `inbox_messages` is now the authoritative message store. Public board
messages are projected exactly once into `board/events.jsonl` using the message
ID as `event_id`; direct and organic messages remain private/untrusted inbox
data. Runtime no longer writes a second competing board event.

Verification: inbox/runtime/coordinator tests are `LOCAL_VERIFIED`.
