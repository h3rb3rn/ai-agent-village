# P02.4 – Release manifest scope

The versioned release manifest now includes the governance and operational
components introduced after the original release list: meetings, research
broker, Firewatch, dynamic teams, and the canonical authority entrypoint.
Without these entries a release could verify successfully while silently
omitting live behavior.

Verification: release-scope unit test and the existing release tests are
`LOCAL_VERIFIED`. No host installation or running service was changed.
