# P134 – Container-Labor und M10 sichtbar und nutzbar machen

## Trigger

> "Es gibt eine installierte Podman Instanz auf dem Agent Host auf der die Agents eigene
> Container deployen/bauen dürfen. Das hat bisher noch niemand genutzt"
>
> "Die verfügbare M10 auf dem Host ist zum experimentieren, training oder was auch immer."

## Befund (N06-M10, read-only, 2026-10-10)

- `/usr/bin/podman` und `/usr/bin/buildah`: `root:ai-village-containers 0750`; `skopeo` für alle ausführbar.
- `ai-village-containers` enthält nur 6 Agents. **02-explorer, 05-interpreter, 08-logician fehlen**, obwohl
  `ROLE_CAPABILITIES['resident']` in `village/authority.py` Container für jede Rolle `resident` vorsieht
  (Provisioning-Fehler auf dem Host).
- `/dev/nvidia*` 0666, alle Agents in `ai-village-gpu`, `/etc/cdi/nvidia.yaml` vorhanden,
  4× Tesla M10 (Compute 5.0, Treiber 535), 0 % genutzt. Keine GPU-Software auf dem Host
  (kein CUDA-Toolkit, torch, numpy, llama.cpp, Ollama).
- Agent-Units haben keine Netzsperre; Policy `insecureAcceptAnything`, Registries per voll
  qualifiziertem Namen erreichbar.
- Prompt und Fähigkeitszeile lasen sich wie ein Download-Verbot („no unpinned downloads“,
  „external knowledge only through research_request“, intern `pull_policy: never`), und die
  Fähigkeitszeile sagte nur „Rootless containers: ready“ ohne Hinweis, was damit möglich ist.

## Änderungen

- `web/runtime.py`: neue Funktion `lab_guidance()`, angehängt an die Fähigkeitszeile (`capability_summary()`):
  - mit Podman: eigene Images bauen, öffentliche Images per Digest pinnen
    (`skopeo inspect` → `podman pull …@sha256:`), nie `--privileged`;
  - ohne Podman: über King die Capability `containers` anfordern;
  - GPU-Zeile mit Anzahl/Modell, Maxwell-Hinweis (sm_50) und `--device nvidia.com/gpu=all`.
- `village/containers.py`: `describe_agent_capabilities()` liefert die GPU-Geräteliste mit.
- `prompts/resident-system.txt`: HABITAT-Absatz erlaubt ausdrücklich eigene Images und
  gepinnte Pulls; die M10 sind „yours to experiment, train or serve models on“. Die
  Sicherheitszeilen (Rezepte prüfen, keine privilegierten Container, Credentials) bleiben unverändert.
- `tests/test_prompt_gaps.py`: Längenlimit 14450 → 14650 (begründet).
