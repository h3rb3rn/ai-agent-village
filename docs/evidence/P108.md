# P108 – Falsch große Porträts blockieren nicht mehr das ganze Profil

## Befund (HOST_VERIFIED, 2026-10-09, 18:22 und 18:12 UTC)

- Librarian und Methodologist haben ihr Profil über `profile_operation` geschrieben, es wurde aber abgelehnt: `Invalid ASCII art: ASCII art must have exactly 250 lines (got 7)` bzw. `(got 9)`.
- Die Ablehnung betraf das ganze Profil. Beruf, Berufung, Ziele, Vorlieben und Hobbys wurden also nicht gespeichert, obwohl sie korrekt waren. Dadurch blieb die Profil-Pflicht bestehen.

## Änderung

`village/residents.py`, `update_profile()`:
- Ein ungültiges Porträt wird nicht mehr als Fehler behandelt. Die Textfelder werden gespeichert, das Porträt behält seinen bisherigen Wert.
- Das Ergebnis enthält `art_warning` mit der Fehlermeldung, damit der Agent sie sieht.
- Gültige Porträts werden wie bisher gespeichert.

## Tests (LOCAL_VERIFIED)

- `tests/test_residents.py`: `test_wrong_size_portrait_does_not_block_the_text_fields`.
- Gesamte Suite: siehe Commit.

## Offen

- Die 250-Zeilen-Vorgabe wird von den Agents nicht erfüllt. Das Porträt bleibt damit leer, bis ein Agent eine gültige Fassung schickt oder eine Generierung eingeführt wird. Das ist eine Designfrage, nicht Teil dieses Pakets.
